# قصة — موقع عرض المنتج

موقع عرض سينمائي (وليس متجرًا إلكترونيًا) لتي شيرت قصة، مبني بـ Next.js 15 / React / TypeScript / Tailwind / Framer Motion.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## هيكل الموقع

- **الصفحة الأولى** (`app/page.tsx`): عرض سينمائي بالتمرير، مع محدد ألوان علوي.
- **الصفحة الثانية** (`app/product/page.tsx`): تفاصيل المنتج (صورة تطريز مقرّبة، عنوان، وصف، وقسم القماش).

## تعديل النصوص والألوان (بدون لمس الكود)

كل المحتوى القابل للتعديل موجود في ملف واحد:

```
content/product.ts
```

من هناك يمكنك تعديل:
- اسم العلامة والمنتج
- عنوان ووصف التصميم
- نص قسم القماش وتفاصيله
- قائمة الألوان المتاحة (label / swatch / folder / imageCount)

## إضافة أو استبدال الصور

الصور مقسّمة حسب اللون داخل:

```
public/products/<اسم المجلد>/
  1.jpg
  2.jpg
  3.jpg
  4.jpg
  close.jpg   ← صورة مقرّبة للتطريز (تُستخدم في الصفحة الثانية)
```

الصور الحالية في المشروع هي صور بديلة (placeholders) بألوان العلامة، فقط لإظهار الهيكل والحركة.
استبدلها بصورك الحقيقية بنفس الأسماء ونفس المجلدات — الموقع سيعرضها تلقائيًا دون أي تعديل في الكود.

لإضافة صور أكثر من 4 للون واحد: أضف `5.jpg` وهكذا، وحدّث `imageCount` في `content/product.ts` لنفس اللون.

## إضافة لون جديد بالكامل

1. أنشئ مجلدًا جديدًا داخل `public/products/` (مثلاً `green`).
2. ضع بداخله `1.jpg` ... `close.jpg`.
3. أضف عنصرًا جديدًا لمصفوفة `colors` في `content/product.ts` بنفس الاسم (`folder: "green"`).

سيظهر اللون تلقائيًا في محدد الألوان أعلى الصفحة الأولى.

## ملاحظات

- الموقع بالكامل RTL وباللغة العربية (`lang="ar" dir="rtl"`), بخطي Noto Kufi Arabic (العناوين) و IBM Plex Sans Arabic (النصوص).
- تجربة التمرير تستخدم `scroll-snap` + Framer Motion لحركة سينمائية سلسة بين الصور.
- تبديل اللون يستخدم انتقال fade + blur + scale لكامل مجموعة الصور.
- المشروع جاهز للتوسّع لاحقًا إلى متجر إلكتروني كامل دون إعادة هيكلة.
